# OnlineShop - E-Commerce Web Application (Academic Project)

A full-stack e-commerce web application built in PHP and MySQL to demonstrate practical software development skills in web application architecture, database integration, user authentication, order tracking, and profile management.

### Live demo:

https://onlineshop.morganugochukwu.com/shopping_cart/index.php

## Project Overview

OnlineShop is a database-driven web application that simulates a real-world retail experience for both customers and administrators. It was developed as a portfolio project to strengthen my understanding of backend logic, data handling, session management, role-based access, and user-centred product workflows.

The system enables users to:
- Register and create accounts
- Log in securely
- Browse products
- Add products to a shopping cart
- Place orders
- Track pending and completed orders
- Manage user profiles
- Upload profile images
- View personal order history

## Core Workflow

1. Users browse products from the storefront.
2. Registered customers can add items to their cart.
3. User authentication validates and protects account access.
4. Customer orders are tracked by status such as pending or paid.
5. Admin users can upload, update, and remove products as part of the store management flow.

## Database Design

The application uses a MySQL database with separate operational tables for:

- Users
- Product inventory
- Cart/order data

This project demonstrates my understanding of relational data structures, stored values, and application-to-database interaction using server-side logic.
